# FocusMate

FocusMate is a Java Swing–based productivity application designed to help users stay focused through structured sessions and shared accountability. The application includes user authentication, a dashboard, and interactive panels.

## How to Run
1. Open the project in IntelliJ IDEA.
2. Locate the `Main.java` file inside the `src` folder.
3. Click the Run (▶️) button or run the `Main` class.

## Technologies Used
- Java
- Java Swing
- IntelliJ IDEA
